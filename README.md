## 🎮 프로젝트 소개 (Overview)

**데카르트핏(Descartes Fit)**은 1904년 탄생한 세계적인 실시간 주식·상품 거래 보드게임 **'핏(Pit)'**의 박진감 넘치는 물물교환 메커니즘을 고등학교 수학 함수에 결합한 차세대 수학 교육용 웹 애플리케이션입니다.

- **실시간 호가 거래 & 세트 수집:** 순서(턴) 없이 동시에 카드를 맞교환하여 자신이 목표로 하는 한 종류의 함수 카드 9장을 가장 먼저 독점 수집하고 중앙의 종을 쳐서 **"FIT!!"**을 외치면 승리합니다.
- **닌텐도 디자인 시스템 (Nintendo Design System):** 따뜻한 게임 테이블 매트, 실제 눌리는 3D 아케이드 버튼, 3D 황금 데스크 벨, 만화풍 호가 말풍선(`game-speech-bubble`), 친근하고 굵은 게임 서체(`'Jua'`, `'GmarketSans'`)를 적용하여 교실 스마트보드와 학생 태블릿에서 최고의 시각적 몰입감을 선사합니다.
- **교실 스마트보드 P2P 무설치 멀티플레이어:** 교사 전자칠판에 뜬 4자리 룸코드 및 고화질 **QR 코드**를 학생들이 스마트폰 카메라로 스캔하여 즉시 WebRTC P2P로 직접 연결됩니다.

## 📚 2022 개정 고1 공통수학 엄격 준수 가이드라인

- **4대 허용 함수 계열:** 오직 **일차함수(Linear), 이차함수(Quadratic), 유리함수(Rational), 무리함수(Irrational)** (총 36장)만 기본 덱으로 사용합니다.
- **미적분 '극값(극대/극소)' 배제 원칙:** 아직 미적분을 배우지 않은 고1 학생들을 위해 '극값' 용어를 일체 배제하고, 중3/고1 교육과정에 부합하는 **"최댓값 / 최솟값 (꼭짓점의 y좌표)"**으로 정확히 대체하였습니다.
- **삼각함수 '주기함수' 배제 원칙:** 주기함수는 고2 일반선택 '수학Ⅰ'에서 처음 등장하므로 고1 모드에서는 등장하지 않으며, 고2/고3 심화 코스 선택 시에만 선택적으로 활성화됩니다.

## 🕹️ 5대 게임 모드 (Game Modes)

1. **🔔 데카르트 핏 (Descartes Pit - 메인 모드)**
   - 실시간 함수 카드 물물교환 & 9장 세트 완성 핏 배틀
   - 인원수 스케일링: 2인 듀얼(18장) / 3인 삼파전(27장) / 4인 표준(36장)
   - 4대 운영 변형 룰: 정통 핏 / 🤫 무언(손가락) 핏 / 👁️ 오픈 핸드(초보자 멘토링) / 🤝 2:2 듀오 팀전
   - 3단계 학습 속도: 🎓 수학 학습 모드(6초 여유 + 교환 리포트 일시정지) / ⚡ 표준(3.8초) / 🔥 스피드(2.2초)
2. **🃏 데카르트 X (Descartes X - 공통 성질 털기)**
   - 바닥에 놓인 카드와 공통점(같은 함수 계열 또는 대칭성, 점근선, 증감 등)을 공유하는 카드를 내려놓아 손패를 먼저 0장으로 만드는 우노(UNO) 스타일 게임
3. **⚔️ 데카르트 Y (Descartes Y - 좌표 함숫값 배틀)**
   - 제시된 좌표($x=1, x=2, y절편$ 등)에서 함숫값 $f(x)$가 더 큰 카드를 출전시켜 점수를 겨루는 탑트럼프(Top Trumps) 스타일 암산 배틀
4. **⚡ 스피드 매칭 (Property Rush)**
   - 45초 동안 제시되는 수학적 조건(대칭축, 점근선, 최솟값 등)에 부합하는 카드를 빠르게 골라 콤보 점수를 쌓는 스피드 퀴즈
5. **🧭 함수 도감 랩 (Function Dex Lab)**
   - 72종 전 계열 함수의 직교좌표계 인터랙티브 그래프 줌/패닝 및 실시간 $(x, y)$ 좌표 추적 학습 도감

## 🛠️ 기술 스택 (Tech Stack)

- **Core:** React 18, TypeScript 5.7, Vite 6
- **Styling:** Tailwind CSS 3.4, Nintendo Design System Theme
- **Fonts:** Jua (주아체), GmarketSansBold, Pretendard, Geologica
- **Graphics & Audio:** HTML5 Canvas 2D (Cartesian Coordinate Plotter), Web Audio API Sound Synthesizer
- **Networking:** PeerJS (WebRTC DataChannel P2P Serverless Multiplayer), QRCode.react
- **Effects:** Canvas-Confetti, Lucide React Icons

## 🏫 교실 수업 활용 팁 (Pedagogy)

1. **수업 도입 5분:** `데카르트 핏 (무언 핏 모드)`으로 학생들의 흥미를 유발하고 함수 식 분류 감각을 일깨웁니다.
2. **개념 형성 20분:** `🎓 수학 학습 모드`를 켜고 교환할 때마다 뜨는 **[새로 획득한 함수 탐구 모달]**을 통해 짝꿍과 함께 꼭짓점과 점근선을 1문장씩 소리 내어 확인하도록 지도합니다.
3. **수업 마무리 10분:** `데카르트 Y` 또는 `스피드 매칭`을 통해 함숫값 대입 및 그래프 성질 형성평가를 진행합니다.
